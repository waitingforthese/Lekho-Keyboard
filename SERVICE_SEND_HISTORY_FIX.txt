LEKHO KEYBOARD V1.6.6 — SEND/EXTERNAL SEND HISTORY FIX
GitHub Website only. Keep the current V1.6.5/V1.6.4 service code and apply these small edits
to: app/src/main/java/com/example/lekho/keyboard/LekhoInputMethodService.kt

WHY:
- Keyboard Enter already calls commitCurrentTokenAndSeparator().
- Some apps use their own SEND button. The editor clears its text while the IME remains open.
- The old service only refreshed suggestions in onUpdateSelection(), so that externally-cleared
  composing word could remain pending and never be recorded reliably.
- This patch detects that the composing word disappeared from the editor and saves it to
  local history WITHOUT writing the word back into the now-empty message box.

1) ADD THIS PROPERTY beside saveTypingAfterPause:

    private val reconcileExternalEditorChange =
        Runnable { finalizeTokenAfterExternalEditorChange() }

2) REPLACE the current onUpdateSelection() body with:

    override fun onUpdateSelection(
        oldSelStart: Int,
        oldSelEnd: Int,
        newSelStart: Int,
        newSelEnd: Int,
        candidatesStart: Int,
        candidatesEnd: Int
    ) {
        super.onUpdateSelection(
            oldSelStart, oldSelEnd, newSelStart, newSelEnd, candidatesStart, candidatesEnd
        )

        if (typingTokenActive && !isSensitiveField()) {
            typingPauseHandler.removeCallbacks(reconcileExternalEditorChange)
            typingPauseHandler.postDelayed(reconcileExternalEditorChange, 120L)
        }
        if (root != null) refreshTopStrip()
    }

3) ADD THIS HELPER immediately before scheduleTypingPauseSave():

    private fun finalizeTokenAfterExternalEditorChange() {
        if (!typingTokenActive || isSensitiveField()) return

        val token = composingTokenBuffer
        if (token.isBlank()) return

        val probeLength = (token.length + 32).coerceIn(64, 256)
        val textBeforeCursor = currentInputConnection
            ?.getTextBeforeCursor(probeLength, 0)
            ?.toString()
            .orEmpty()

        // Still present: this is a normal composing update, not an external Send/clear.
        if (textBeforeCursor.endsWith(token)) return

        val alreadySavedDuringPause =
            lastIdleSavedToken == token && lastIdleSavedMarathiMode == marathiMode
        val completedWord =
            if (marathiMode) WordEngine.transliterate(token) ?: token else token

        if (!alreadySavedDuringPause) remember(completedWord)

        typingPauseHandler.removeCallbacks(saveTypingAfterPause)
        typingTokenActive = false
        composingTokenActive = false
        composingTokenBuffer = ""
        lastIdleSavedToken = null
        lastIdleSavedMarathiMode = null
        refreshTopStrip()
    }

4) REPLACE onFinishInputView() with:

    override fun onFinishInputView(finishingInput: Boolean) {
        stopBackspaceRepeat(refresh = false)
        typingPauseHandler.removeCallbacks(saveTypingAfterPause)
        typingPauseHandler.removeCallbacks(reconcileExternalEditorChange)

        if (typingTokenActive || composingTokenActive) {
            val token = composingTokenBuffer
            val probeLength = (token.length + 32).coerceIn(64, 256)
            val textBeforeCursor = currentInputConnection
                ?.getTextBeforeCursor(probeLength, 0)
                ?.toString()
                .orEmpty()

            if (token.isNotBlank() && textBeforeCursor.endsWith(token)) {
                // The word is still in the editor. Finalize it normally.
                commitCurrentTokenAndSeparator()
            } else {
                // The app's Send action already cleared the editor. Save history only;
                // do NOT insert the sent word back into the empty editor.
                finalizeTokenAfterExternalEditorChange()
            }
        }
        super.onFinishInputView(finishingInput)
    }

IMPORTANT:
- Do not modify the 2000 ms pause-save delay.
- Do not remove `remember()` from commitCurrentTokenAndSeparator().
- Do not modify the composition/suggestion code, automatic suggestion space, history cap,
  password-field exclusion, or long-press Backspace.
- Expected result: keyboard Enter/IME Send continues to save the word; app-specific Send button
  that clears the text field also saves the active word once and does not reinsert it.
